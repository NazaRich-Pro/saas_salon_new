## 🚀 Deployment Instructions

### Quick Deploy
```bash
# 1. On VPS
git clone <your-repo> /opt/saas_salon
cd /opt/saas_salon

# 2. Initialize
make init
# This will:
#   - Install Docker
#   - Configure firewall
#   - Build images
#   - Run migrations
#   - Create superuser
#   - Start services

# 3. Load email templates
make shell
>>> from django.core.management import call_command
>>> call_command('load_default_templates')
>>> exit()

# 4. Configure DNS
# Point saas.akylman.online and *.saas.akylman.online to your VPS IP

# 5. Wait for TLS certificates (~2 min)

# 6. Access
https://saas.akylman.online
```

**Done! Your SaaS is live!**

### SMTP Configuration

**Gmail:**
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
```

**Yandex:**
```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=587
SMTP_USER=your-email@yandex.ru
SMTP_PASS=your-password
```
